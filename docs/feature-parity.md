# 機能対応表（旧HTML版 ⇔ 新SaaS版）

作成日: 2026-09-12 / 目的: 旧版の機能が漏れなく引き継がれているかを、いつでも一目で確認できるようにする。

運用: **各フェーズの完了時に、このファイルの状態列を更新する。**

## 凡例

| 記号 | 意味 |
|---|---|
| ✅ | 実装済み・dev環境で動作確認済み |
| 🚧 | 一部実装（範囲を絞って実装、または画面はあるが連動未実装） |
| ⏳ | 未着手（実装予定。対応フェーズが決まっている） |
| 🔮 | 未着手・実装するか検討中（優先度低 or 必要性を見て判断） |
| ➕ | 旧版には無い、SaaS化に伴う新規機能 |
